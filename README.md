# Popcorn+ — versions

Versions de l'application Popcorn+ pour Android TV (APK).

Popcorn+ est un lecteur : il ne fournit aucun contenu. Il lit uniquement les playlists M3U ou Xtream Codes que l'utilisateur ajoute lui-même.

- **Dernière version** : [popcorn-plus-tv.apk](https://github.com/amineautoformation-dev/popcorn-plus-releases/releases/latest/download/popcorn-plus-tv.apk)
- **Historique** : onglet [Releases](https://github.com/amineautoformation-dev/popcorn-plus-releases/releases)

Une fois installée, l'application propose elle-même les nouvelles versions.
